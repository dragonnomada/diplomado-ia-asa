# Inteligencia Artificial

Aeropuertos y Servicios Auxiliares (ASA)

## Temario

> **Módulo 1** - Sistemas cognitivos y representación del conocimiento
>
> 20 horas

1.1. Fundamentos de sistemas cognitivos

1.2. Arquitecturas de representación del conocimiento

1.3. Lógica difusa e inferencia en entornos de software

1.4. Ontologías y grafos de conocimiento

1.5. Aplicación práctica en la optimización de procesos

> **Módulo 2** - Data Science
>
> 20 horas

2.1. Metodología del flujo de trabajo en Data Science 

2.2. Adquisición, limpieza y transformación de datos 

2.3. Análisis exploratorio de datos (EDA) 

2.4. Estadística descriptiva e inferencial aplicada 

2.5. Modelado analítico e interpretación de resultados

> **Módulo 3** - Python para la inteligencia artificial
> 
> 25 horas

3.1. Entornos de desarrollo y librerías clave (NumPy, Pandas) 

3.2. Manipulación y estructuración de datasets avanzados 

3.3. Visualización de datos (Matplotlib, Seaborn) 

3.4. Implementación de scripts optimizados para IA 

3.5. Integración de APIs y flujos de datos automatizados 
 
> **Módulo 4** - Machine Learning
> 
> 25 horas

4.1. Algoritmos de aprendizaje supervisado (Clasificación/Regresión) 

4.2. Algoritmos de aprendizaje no supervisado (Clustering) 

4.3. Evaluación, validación cruzada y métricas de desempeño 

4.4. Optimización de hiperparámetros y selección de características 

4.5. Despliegue e integración de modelos analíticos 

> **Módulo 5** - Redes neuronales
> 
> 30 horas

5.1. Fundamentos de arquitectura perceptrón y redes densas 

5.2. Funciones de activación, optimizadores y propagación hacia atrás 

5.3. Introducción a redes neuronales profundas (Deep Learning) 

5.4. Redes para procesamiento de series temporales/texto/visión 

5.5. Proyecto integrador: Diagnóstico y solución con IA en ASA
